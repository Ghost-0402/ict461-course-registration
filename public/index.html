About this demo

This is a teaching prototype for ICT461 (Web standards and HTTP fundamentals). Data is stored in memory on the server and is reset whenever the server restarts. It does not use a real database or authentication.

Your programme choice is remembered between visits using localStorage, which persists until explicitly cleared. sessionStorage would behave differently: it would only last for the current browser tab and would be cleared as soon as that tab is closed, so it is better suited to short-lived, per-tab state rather than a lasting preference like this one.
